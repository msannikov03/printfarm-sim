## Test models

The real-model tests ([docs/real_models.md](docs/real_models.md)) use a few openly licensed 3D models (CC0, public
domain, CC BY 4.0) from Wikimedia Commons. They are not in this repository: `python -m real.fetch_models` downloads
them into `real/assets/models/` (gitignored) and writes their attributions to `real/assets/models/SOURCES.md`. Each
model's title, author, license and source page are listed in [`real/open_models.json`](real/open_models.json).
`real/tests/data/bambu_p1s_*` is BambuStudio's output for geometry generated by `real/mesh_io.py` (ours).

## Protocol references

`real/printer/creality_ws.py` speaks the stock Creality OS websocket protocol. Its message keys and state table
were taken from the Home Assistant integration
[ha_creality_ws](https://github.com/3dg1luk43/ha_creality_ws) (AGPL-3.0), used as a protocol reference only.
The implementation is our own: compared line by line with that project's `ws_client.py` and `utils.py`
@ `a8e5491`, the two share no run longer than one generic line (`import logging`, `return "idle"`).
